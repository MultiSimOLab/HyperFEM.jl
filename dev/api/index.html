Gridap.FESpaces.TrialFESpace — Type
TrialFESpace(space, bc, Λ=0; stage=Λ)

Trial space with the Dirichlet values of bc at the load Λ and the stage τ = stage (see Prescription). The values are set through a dirichlet_applicator built for the occasion; a driver keeps its own applicators (one per space) and uses the TrialFESpace! methods below.

HyperFEM.ComputationalModels.BoundaryCondition — Type
BoundaryCondition(tag, value, load=nothing; mask=nothing)

Single boundary condition on the boundary tag. Whether it is applied as a Dirichlet or a Neumann condition is decided by the user (or driver) consuming it.

  • value: a Prescription, or the space argument of a Separable prescription.
  • load: the load argument of a Separable prescription (only if value is not a Prescription).
  • mask: components to be constrained, e.g. (true, false, true). Default: all components.

HyperFEM.ComputationalModels.Coupling — Type
Coupling(g)

The state of another problem prescribed on a boundary: g(τ) returns a field (FEFunction, CellField, Interpolable) or a function of x, evaluated at the stage parameter τ of the solver, the same one res(τ) receives. In a staggered loop g typically interpolates between the previous and the current stage of the other field, τ -> uh⁻ + (uh⁺ - uh⁻) * τ, and the field may live only on the faces of the tag (an FESpace on an interface). See Prescription.

HyperFEM.ComputationalModels.Prescription — Type
Prescription

What is prescribed on a boundary. p(Λ, τ) returns an object accepted by Gridap for a single tag: a Number/VectorValue, a function of the coordinates x -> value, or a CellField.

Two parameters are passed by the drivers:

  • Λ, the load: the parameter of the loading programme of the whole simulation. Separable and NonSeparable prescribe values as functions of it.
  • τ, the stage: the parameter of the solver, the one res(τ) and jac(τ) receive. A Coupling prescribes the state of another problem as a function of it.

They coincide in a static or monolithic solve; in a staggered loop Λ runs over the ramp of the step while τ runs from 0 to 1 inside it (see StaggeredModel). p(Λ) is p(Λ, Λ).

HyperFEM.ComputationalModels.StaticLinearModel — Type
StaticLinearModel(lf, bf, U, V, dirichlet; assem_U, ls, xh, backend=:gridap)
StaticLinearModel(bf, U, V, dirichlet; assem_U, ls, xh, backend=:gridap)
StaticLinearModel(lfs::Vector, bf, U0, V0, dirichlet; assem_U0, ls, backend=:gridap)

Linear problem bf(u, v) = lf(v). The first form assembles matrix and vector at construction; the second only the matrix (the right-hand side is given to solve! or built by the model's functors); the third solves one matrix for several right-hand sides lfs on the repeated spaces of U0, V0. backend selects who assembles (see linear_system): :gridap (default) or :kernel (HyperFEMKernels extension, using HyperFEMKernels).

HyperFEM.ComputationalModels.StaticNonlinearModel — Type
StaticNonlinearModel(res, jac, U, V, dirichlet; neumann=nothing, nls, xh, xh⁻, backend=:gridap)

res(τ) and jac(τ) are functions of the stage parameter τ of the solver. dirichlet are the BoundaryConditions of U; neumann, if any, the NeumannConditions added to the residual by the driver at the load of every step. The model owns the Dirichlet applicators of its spaces (get_applicators: those of U, ∆U and the space of xh⁻). backend selects the algebraic operator (see build_operator).

HyperFEM.ComputationalModels.component_LInf — Function
component_LInf(u, direction, [Ω])::Float64

Calculate the maximum absolute value of a component of a vector-valued field u. The direction can be a symbol (:x, :y or :z), a component index or a VectorValue. The field is evaluated at the nodes of a first order discontinuous space over Ω, so for higher order fields this is an approximation of the L-inf norm. By default, Ω is the triangulation where the function is defined. It could be useful to find the maximum displacement.

Examples

x_max = component_LInf(uh, :x)
y_max = component_LInf(uh, 2)
d_max = component_LInf(uh, VectorValue(1.0, 1.0, 0.0) / √2)

HyperFEM.ComputationalModels.interpolate_L2_field — Function
interpolate_L2_field(x, dΩ, [Ω₂], [T])

Interpolate an L2 field into an H1 field. The field x is first projected onto a piecewise-constant space defined over the triangulation of the measure dΩ, and then interpolated into a continuous space. The type of the field is inferred from the cell field x and the measure dΩ. Optionally, a destination triangulation Ω₂ can be specified, being different from the triangulation of dΩ.

HyperFEM.ComputationalModels.residual_Neumann — Method
residual_Neumann(bc, v, dΓ, Λ)

Neumann contribution -∑ ∫(v ⋅ fᵢ) dΓᵢ to the residual at the load Λ, one term per condition of bc (dΓ from get_Neumann_dΓ). Inside a staggered loop the load is not the parameter of res(τ): give the conditions to the model (neumann = NeumannConditions(model, bc, degree)) and the driver adds this term at the right load.

HyperFEM.DiscreteModeling.EvolutionFunctions.ramp — Function

Return a bounded ramp function from 0 to 1. By default, the slope is the identity. Otherwise, the scaling factor is 1/T.

\[f(t) = \begin{cases} 0 &, t < 0 \\ t/T &, 0 \leq t < T \\ 1 &, t \geq T \end{cases}\]

HyperFEM.DiscreteModeling.EvolutionFunctions.smoothstep — Method

Return a sigmoid-like function centered at T and edges at ±ϵ. by default, T=ϵ.

\[u(t) = \frac{t - T + \epsilon}{2\epsilon} \\[10pt] f(t) = \begin{cases} 0 &, u < 0 \\ 3u^2 - 2u^3 &, 0 \leq u < 1 \\ 1 &, u \geq 1 \end{cases}\]

source
HyperFEM.DiscreteModeling.EvolutionFunctions.triangular — Method

Return a triangular evolution function ranging from 0 to 1, centered at Tmax, having edges at T0 and 2Tmax-T0. By default, T0=0 and Tmax=T.

\[f(t) = \begin{cases} 0 &, t < T_0 \\ \frac{t-T_0}{T_{max}-T_0} &, T_0 \leq t < T_{max} \\ 1-\frac{t-T_{max}}{T_{max}-T_0} &, T_{max} \leq t < 2T_{max}-T_0 \\ 0 &, t \geq 2T_{max}-T_0 \end{cases}\]

Initialize the state variables for the given constitutive model and discretization. The constitutive model passed to the function will determine the type of the state variables, e.g., a vector, tensor, tuple of state variables...

HyperFEM.PhysicalModels.EightChain — Type

Simplified eight-chain model by Arruda and Boyce. the implementation uses the first five terms of the inverse Langevin function.

\[\Psi = C_1 \sum_{i=1}^{3} \alpha_i \beta^{i-1} (I_1^i - 3^i)\]

HyperFEM.PhysicalModels.IsochoricNeoHookean3D — Type

Neo-Hooke hyperelastic model

source
HyperFEM.PhysicalModels.PlaneStressIncompressible_I1PD — Type

Plane stress incompressible linear I1 pressure distorsion

\[\Psi = F ⊙ F + λ_{33}^2 - 3*(J(F)*λ_{33})^(2/3)\]

source
HyperFEM.PhysicalModels.ViscousPolyconvex — Type

Polyconvex viscoelastic constitutive model for the set of variables {F, J, Cᵥ}, where F is the deformation gradient, J is the jacobian and Cᵥ is the viscous strain.

Key features:

  • Factorization-free: Fast calculation of the intermediate state without matrix factorizations.
  • Neo-Hookean equilibrium: Uses a neo-Hookean expression for the underlying equilibrium term.
  • Distortional invariants: Formulated using distortional invariants rather than deviatoric ones.

Fields

  • μ::Float64: Shear modulus.
  • τ::Float64: Relaxation time.
  • Δt::Base.RefValue{Float64}: Reference to the time step.

HyperFEM.PhysicalModels.Yeoh3D — Type
